# 诗遇 · poetry-resonance

唐诗宋词共鸣 skill，为 WorkBuddy / CodeBuddy 等 agent 打造。以李白诗库为起点，把诗词和真实生活连起来。

## 为什么做这个 skill

起点很简单：收拾书架的时候，翻出一本关于李白的小书。想着刚好重新学一学——每天练练字、读读诗。但学完之后呢？怎么学以致用？

于是有了这个 skill：让学到的诗回到生活里。看到瀑布会想起"飞流直下三千尺"，项目上线会想起"轻舟已过万重山"，朋友远行会想起"我寄愁心与明月"。诗不该只躺在书架上。

它从一个人的真实需求出发建立，也相信很多人有同样的场景——离开学校很久，偶尔读到一句诗，又觉得很有意思。如果你也想让诗词回到自己的生活里，欢迎用，也欢迎一起扩充诗库。

## 功能

- **模式 A · 有感而发**：描述一段经历、场景或心情 → 匹配诗词 → 生成朋友圈 / 小红书文案
- **模式 B · 学习沉淀**：给一首诗 → 人话拆解创作背景与古今映射 → 输出学习笔记，自动记录学习进度
- **模式 C · 今日日签**：结合节气 / 季节 / 日期推荐一首诗，附金句口令与寓意期盼
- **模式 D · 复习验收**：艾宾浩斯遗忘曲线间隔复习（1/2/4/7/15/30 天）+ 背诵验收，题型含诗遇独有的"场景联想题"（给生活场景答诗句）

## 诗库（两层）

- **底库**：李白全集 1149 首（`references/libai_raw.json`，数据来自 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)，MIT），用于原文自动核对与全集检索——引用诗句不靠模型记忆，杜绝背错原文
- **精读库**：27 首名篇人工精读（`references/poems.md`），每首含原文、人话背景、情绪内核、生活·工作共鸣场景、金句、配图意境、日签关联，持续扩充，结构预留扩展杜甫、苏轼、王维等诗人

## 安装

```bash
git clone https://github.com/bonniegeng-max/poetry-resonance.git
cp -R poetry-resonance/poetry-resonance ~/.workbuddy/skills/
```

CodeBuddy 用户目标目录为 `~/.codebuddy/skills/`。

安装后在新会话中说"配首诗"、"拆解这首诗"、"今日一句"或"复习"即可触发。
